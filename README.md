# 戦略的じゃんけん (Strategic RPS) 要件定義書

## 1. プロジェクト概要
文化祭で所属ゼミが模擬店としてミニゲームセンターを出店する。そこで、本プロジェクトでは「戦略的じゃんけんゲーム」を開発する。
モニターと操作機を用いたUI操作と、実際に動く2つのロボットハンドを組み合わせ、プレイヤーに心理戦と視覚的なインパクトを提供する。
ハードウェアに直接触れない設計にすることで、機器の破損を防ぎつつ、ゲームセンターのような体験を作り出す。また、ゲーム進行は操作機を用いるゲーム性にすることにより、恥ずかしがり屋なプレイヤーでも参加しやすく設計する。

## 2. システム構成
* **PC:** ゲームの進行管理、UI表示、ハードウェアへの制御命令を行う。
* **モニター:** プレイヤーに自身と相手の残り手札、サポートカード、勝敗を表示する。
* **操作機 (コントローラー):** プレイヤーが手札を選ぶなどゲーム操作に使用する。
* **ロボットハンド (左右計2台):** M5StickCからの信号を受け取って「グー・チョキ・パー」を物理的に表現する。
* **M5StickC** PCからの信号を受け取り、ロボットハンドを制御する

## 3. ゲームルールと進行
1. **初期手札:** プレイヤーとコンピュータの両方に、決められた手札（グー・チョキ・パー）とサポートカードが配られる。
2. **カード選択:** プレイヤーは操作機を使い、モニター上で制限時間内に出すカードを選択する。
3. **物理アクション:** 選択完了後、PCからマイコンへ信号が送られ、左右のロボットハンドが同時にポーズを作って勝敗を可視化する。
4. **サポートカード:** 「相手は次のターン、グーを出せない」「あいこの場合は自分の勝ちになる」など、状況を有利にする特殊カードを要所で使用可能。
5. **勝敗条件:** お互いの手札が無くなるまで戦い、最終的な勝ち数が多い方の勝利。

## 4. 敵の思考回路
敵（コンピュータ）の行動パターンは、完全にランダムではなく、以下のロジックを組み合わせて「賢さ」を演出する。
* **手札カウンティング:** 画面上で公開されている相手の残り手札から確率を計算する
* **心理ロジック:** 「人間は負けた直後、さっき自分を負かした手に勝つカードを出しやすい」などの人間特有のクセをif文で突く。
* **ランダム性:** ある程度ランダム性を持たせることにより、コンピュータの次の一手を読みづらくする
