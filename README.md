# 戦略的じゃんけん
[デモ動画(2nd round)](https://github.com/user-attachments/assets/b370f584-cb7d-4985-8c03-1eeb24de6f11)

## ゲーム概要
所属ゼミが文化祭の模擬店にミニゲームセンターとして出店し、自作システムをプレイしてもらう挑戦を行いました。本ゲームは、その自作システムの1つであり、「旗揚げゲーム」と「じゃんけん」を融合させたシステムです。
画面上のデジタルな描画と、ロボットハンド(手のハードウェア)の動きを組み合わせることで、プレイヤーの目を惹きつけたエンターテインメントを提供します。

- **ターゲット:** 文化祭の模擬店の来場者
- **目的:**
  1. ミニゲームセンターの売り上げに貢献する
  2. 来場者に楽しんでもらう
  3. 技術による所属ゼミのアピール

## システム環境構成
- **ハードウェア:** PC, M5StickC（ロボットハンド制御）, 拡張基板（サーボモーター制御）、サブモニター, ジョイパッド（コントローラー）
- **開発言語:** Python 3.13 (PC側), C++ / Arduino (M5StickC側)
- **主要ライブラリ:**
  - **ゲームエンジン・UI描画:** Pygame
  - **シリアル通信:** PySerial
  - **システム制御:** os, sys, platform, math

## コア機能と処理ロジック

### 1. 脳トレアクション・ゲームロジック
上から降ってくる「手（グー・チョキ・パー）」を拾っていくアクションゲームに、旗揚げゲームのような判断要素を追加しています。
- **正解判定アルゴリズム:** 「ロボットハンドが現在出している手」と「画面上の指示（勝て・負けろ・あいこ）」の2つの変数から、プレイヤーが拾うべき「正解の手」を動的に算出。
- **動的難易度調整:** 全3ラウンド制を採用。ラウンドが進むごとに「制限時間の減少（60秒→45秒→30秒）」と「手・指示の切り替わり周期の高速化・非同期化」を行い、難易度を段階的に引き上げます。
- **チュートリアル:** 最初のラウンドで適宜ルール説明を行い、ルールをプレイしながら覚えられる設計を実現。

### 2. M5StickCとのリアルタイム・ハードウェア連携
PySerialを用いて、PCからM5StickCへの単方向・双方向の通信制御を行っています。また、ロボットハンドとM5StickCの間にサーボドライバー基板を中継することで、複数モーターの同時制御と安定した電力供給を可能にしています。
- **状態指示:** ゲーム内の状態変化に合わせて、手の形（`パー`, `グー`, `チョキ`）をM5StickCへリアルタイム送信。
- **生存確認（ハートビート）:** 毎秒PC側からダミー信号（`\n`）を送信し、通信断を防止・検知するフェイルセーフ機構を実装。
- **フィードバック:** 「クリア回数」や「生存確認」の結果をM5StickC側の画面に表示します。

## 操作仕様（プレイヤー＆管理者用コマンド）
イベント運営時のトラブル対応やテストプレイを円滑にするため、キーボード操作対応・管理者用ショートカットを実装しています。

| キー / ボタン | 対象 | アクション |
| :--- | :--- | :--- |
| **十字キー / アナログスティック** | プレイヤー | キャラクターの左右移動 / しゃがみ（急降下） |
| **上キー / コントローラーボタン** | プレイヤー | ジャンプ |
| **スペース / Aボタン** | プレイヤー | ゲームスタート / 画面送り |
| **W** | 管理者 | 強制クリア（現在のラウンドのスコアを目標値にする） |
| **L** | 管理者 | 強制ゲームオーバー（現在のラウンドのHPを0にする） |
| **ESC** | 管理者 | プログラムの安全な終了 |

## 開発の工夫点
- **視覚的なフィードバック:** ダメージを受けると操作キャラクターが点滅する設定にしました。その他にも、体力はハートにしたりポイントゲージに目盛りをつけました。
- **聴覚的なフィードバック:** ダメージ時に効果音を鳴らし、さらなるダメージ感を演出しました。また、ポイントを取得すると正解音を鳴らし、その行動の正しさを暗に示す仕様を心がけました。
- **直感的なUI:** 指示と手が切り替わるタイミングを可視化するため、アナログ時計のような専用タイマーUIを実装。また、1ラウンド目に表示させる操作説明を点滅させ、プレイヤー側の操作を待っていることを伝える設計にしました。
